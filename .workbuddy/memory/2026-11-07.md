## WordVSTO 新增「复制实例信息」命令

- 目的：把当前 Word 实例的身份信息 + 可直接运行的访问代码复制到剪贴板，供大模型精确绑定本实例。
- UI：Ribbon.xml 新增组「实例」/按钮 btnCopyInstanceInfo，回调 BtnCopyInstanceInfo_Click（Ribbon.cs）。
- 关键做法：把 Word.Application 以 item moniker !WordVSTO.Instance.<PID> 注册到 ROT（P/Invoke ole32 的 GetRunningObjectTable + CreateItemMoniker + ComTypes.IRunningObjectTable.Register，flag=0 弱注册，避免僵尸进程）；多 Word 实例也能确定性地区分。
- 剪贴板内容：PID / 进程启动时间 / HWND / WINWORD.EXE 路径 / Word 版本与路径 / 用户名 / 当前文档与打开文档列表 / ROT 注册名；附 Python 3 + pywin32 代码（枚举 ROT 按名字绑定、QueryInterface(IID_IDispatch) -> win32com.client.Dispatch），以及 win32process.GetWindowThreadProcessId 校验 PID、GetObject(docPath).Application 备选方案。
- 本机已装 pywin32（Python 3.13），Python 访问代码经 ast.parse 语法校验通过；Ribbon.xml 经 XML 解析校验通过。
- 备份：Ribbon-bak202611070807.cs、Ribbon-bak202611070807.xml。文件统一 UTF-8 BOM + CRLF。
- 本机安全策略拦截构建工具调用，未做编译验证；需在 Visual Studio 里生成一次确认。
## 精简「复制实例信息」剪贴板输出

- 用户要求：只保留能访问实例的 key，删除派生信息与提示文字；桌面 word process.txt 不处理。
- 现在剪贴板只有一行：!WordVSTO.Instance.<PID>，即 ROT item moniker 的 display name。
- Ribbon.cs 移除了 PID/HWND/版本/文档列表/Python 示例/校验/说明的采集与拼接，以及 GetMainWindowHandle、SafeGet、StringBuilder；BtnCopyInstanceInfo_Click 只剩取 PID + 注册 ROT + SetText。
- Ribbon.xml 更新按钮 screentip/supertip；备份 Ribbon-bak202611070823.cs、Ribbon-bak202611070823.xml。
- 大模型侧用法：枚举 ROT，按 display name 匹配该 key，GetObject -> QueryInterface(IID_IDispatch) -> win32com.client.Dispatch。
