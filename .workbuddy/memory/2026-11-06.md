- 架构：Ribbon XML（Ribbon.cs 实现 IRibbonExtensibility + Ribbon.xml 嵌入资源）；ThisAddIn.cs 重写 CreateRibbonExtensibilityObject；csproj 增加 Compile(Ribbon.cs, XmlRibbon) 与 EmbeddedResource(Ribbon.xml)。与 ExcelVSTO 的 Ribbon.xml 模板风格一致。

- 全部文件统一 UTF-8 BOM + CRLF，末尾 CRLF。
- 本机安全策略拦截构建工具调用，未做编译验证；需在 Visual Studio 里生成一次确认。
